# Orbis Arcana — дорожная карта 2.0

Цель 2.0: мод уровня Iron's Spells и выше — собственный визуал, анимации и звук без ванильных частиц/моделей/звуков,
10 школ × 20+ заклинаний, небольшой лор с новыми структурами, сущностями и боссами.
Работа идёт этапами: этап → отчёт → проверка пользователем → следующий. Статус этапов — в `PROGRESS.md`.

## 0. Принципы

- **Своё, не ванильное.** Частицы — своя система (не `ParticleEngine`), модели — Blockbench (GeckoLib), звуки — свои OGG.
  Ванильное допустимо только как запасной вариант при отключённой графике/доступности.
- **Конвейер ассетов в git.** Исходники `.bbmodel`, частицы, анимации, звуки лежат в `art/`; экспорт — скриптами
  (`tools/*.cjs`) в `src/main/resources`, чтобы всё воспроизводилось и ревьюилось.
- **Шаблоны вместо штучной работы.** 200 заклинаний не делаются по одному с нуля: этапы V1–V7 строят
  параметрические шаблоны (снаряд, зона, луч, призыв, щит, рывок…), а контент-этапы собирают из них заклинания
  с уникальными деталями (модель ядра, эмиттер, звук, анимация).
- **Производительность — бюджет, а не надежда.** Круги и VFX: инстансинг, LOD по дистанции, лимит эмиттеров,
  клиентская настройка качества (Низко/Средне/Высоко/Ультра). Цель: 30 одновременных кастов без просадки ниже 60 FPS
  на средней машине под Sodium + Iris.
- **Совместимость проверяется каждым этапом**, а не в конце (раздел 3).

## 1. Арт-библия (основа для всех этапов)

По референсам пользователя (`Downloads/референсы`: UI-кит «Sigilweave», концепты ChatGPT/Gemini):
- **Стиль:** «тёмная алхимия × современная читаемость» — тёмные сланцевые панели, тонкие золотые рамки,
  бирюзовые акценты интерфейса, цвет школы как подсветка; пиксельная основа Minecraft, но чистая сетка и иерархия.
- **Палитра токенов:** void / slate / surface / gold / teal / mana-blue / astral-violet / danger + 10 цветов школ
  (уже в реестре школ). Редкость = цвет рамки + сложность круга (обычное 1 кольцо … божественное 6+ колец).
- **Рунный алфавит:** ~32 своих глифа (сила, контроль, связь, защита, перенос, ускорение…) — общий язык
  для кругов, иконок, интерфейса и структур.
- **Разрешения:** блоки — 16×16 (ванильные, сочетаются с глубинным сланцем и т.п.); предметы-3D — 32–64 px
  на модель; круги и VFX — 128–256 px (эмиссивные текстуры); иконки заклинаний — 32×32 с рамкой редкости.

## 3. Совместимость (тестовая сборка)

Список модов пользователя; каждый этап проверяется в сборке со всеми ними (Prism-инстанс + Iris с шейдерпаком).
Проверено по Modrinth (02.11.2026): у всех есть сборки NeoForge 26.3, кроме Let Me Despawn (не найден под этим
slug — уточнить источник); Curios, Sodium, Sodium Extra и ScalableLux под 26.3 пока beta/alpha.
Риски, на которые смотрим особо:
- **Sodium / Iris / ImmediatelyFast / BadOptimizations** — свои пайплайны кругов и VFX, батчинг GUI (ImmediatelyFast), эмиссив под шейдерами.
- **Entity Culling / More Culling / Cull Leaves** — сущности-снаряды и призывы не должны пропадать в кадре; круги не сущности.
- **AsyncParticles** — наш VFX не использует ванильный движок частиц, конфликтов быть не должно; проверить.
- **AppleSkin / Jade / Mouse Tweaks** — HUD не перекрывает их, наши экраны не ломают скролл/перетаскивание.
- **Curios / GeckoLib / Player Animation Library** — аксессуары видны вместе с анимациями каста.
- **Lithium / FerriteCore / ScalableLux / Clumps / Let Me Despawn** — серверная логика, сущности `noSave`, свет от VFX не меняет освещение блоков.
- **Cloth Config / MidnightLib / MezzConfig / Architectury / Almanac** — библиотеки; конфиг-экран мода — своими средствами, без жёсткой зависимости.

## 4. Риски и честные оценки

- **Объём.** 170 новых заклинаний с уникальным визуалом — самая большая часть; поэтому сначала шаблоны (V1–V9),
  потом контент. Уникальность — в ядре заклинания (модель, эмиттер, звук), а не в каждом кадре.
- **Звук.** Нужны инструменты: ffmpeg (кодирование OGG) — ставим в V0; звуки синтезируются и сводятся скриптом
  из слоёв, при необходимости — CC0-сэмплы с записью в `NOTICE`.
- **Формат частиц Blockbench** рассчитан на Bedrock — для Java пишем свой загрузчик подмножества (без полного Molang).
- **Версии зависимостей.** GeckoLib и PAL обновляются отдельно от Minecraft — фиксируем версии и проверяем при обновлении MC.
