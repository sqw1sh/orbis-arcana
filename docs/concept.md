## 1. Видение и отличие от референса

### 1.1. Фантазия игрока

> «Я — маг, который **помнит** каждое изученное заклинание. Чем умнее я его использую, тем сильнее оно становится, а каждый каст рождается из моего собственного магического круга.»

### 1.2. Столпы дизайна

1. **Знание навсегда.** Свиток прочитан — заклинание принадлежит персонажу, а не предмету. Гримуар — это интерфейс памяти, а не книга в инвентаре.
2. **Эволюция, а не прокачка цифр.** 15 уровней мастерства; на 5, 10 и 15 заклинание **меняет поведение**.
3. **Круг — сердце каста.** Каждый каст виден через магический круг, который заряжается и выпускает магию. Круг красив для наблюдателя, но не мешает самому игроку.
4. **Школа — это стиль.** Привязка к школе даёт уникальную механику и таланты, но не запрещает другие заклинания.
5. **Открытость.** MIT, data-driven заклинания, публичное API, мягкая совместимость.

### 1.3. Чем мод отличается от Iron's Spells 'n Spellbooks

| Аспект | Iron's Spells | Orbis Arcana |
|---|---|---|
| Где хранятся заклинания | В книге заклинаний / свитках (предмет) | В персонаже навсегда; свиток расходуется при изучении |
| Уровни заклинаний | Уровень свитка задаёт силу | Редкость фиксирована, сила растёт мастерством от использования |
| Развитие | Предметы, атрибуты | Мастерство 1–15 с вехами-трансформациями + резонанс школы |
| Специализация | Через экипировку | Явная привязка к доминантной школе с деревом талантов и ритуалом смены |
| Визуал каста | Анимации и частицы | Процедурные многослойные магические круги, привязанные к типу заклинания |
| Выбор заклинаний | Слоты книги | Радиальное меню 8 × 3 набора из всех изученных |

### 1.4. Чего в v1.0 нет (сознательно)

- Собственное измерение, NPC-кампания, классы, крафт заклинаний из компонентов.
- Боссы и сюжетные испытания (перенесены в v1.1, см. §20).
- Отдельный PvP-баланс (базовая серверная корректность есть, честный соревновательный баланс не обещается).
- Разрушение блоков боевыми заклинаниями по умолчанию (только серверной опцией).

| **Набор (Loadout page)** | Одна из 3 страниц радиального меню по 8 слотов |

## 4. Игровой цикл

```
Исследование мира → находка свитка → изучение (навсегда)
      ↓
Назначение в радиальное меню → бой / поддержка / перемещение
      ↓
Эффективное применение → опыт мастерства + резонанс школы
      ↓
Вехи 5/10/15 меняют заклинание; резонанс даёт очки талантов
      ↓
Более сложный контент → более редкие свитки → ...
```

**Онбординг [≈]:** при первом входе в мир игрок получает книгу-подсказку «Первые печати» (обычный предмет-туториал) и **1 свиток Обычной редкости случайной стихийной школы**. Гримуар доступен сразу, школа не выбрана (нейтральное состояние).

## 5. Заклинания: модель, типы, редкость

### 5.1. Структура заклинания

Каждое заклинание описано JSON-файлом в датапаке (§15.4) и состоит из:

- `school`, `rarity` — фиксированы навсегда [✔];
- `behavior` — тип серверной логики, реализованный в Java (снаряд, луч, зона, рывок, щит, аура…);
- `targeting` — тип размещения круга (§5.2);
- `cast` — режим каста (§5.3), время подготовки;
- `cost`, `cooldown`, `params` — числа;
- `primary_stat` — какой параметр растёт на обычных уровнях мастерства;
- `milestones` — изменения на 5/10/15;
- `circle` — ссылка на описание геометрии круга (§9.6).

### 5.2. Типы размещения (targeting) [✔]

| Тип | Где появляется круг | Примеры |
|---|---|---|
| `DIRECTIONAL` | Перед руками / концом посоха / над раскрытым фолиантом, ориентирован по взгляду | Снаряды, лучи, конусы |
| `GROUND` | На поверхности в точке, куда смотрит игрок (до макс. дальности) | Зоны, метеоры, ловушки |
| `TARGET` | Под ногами выбранной цели (союзник или враг) | Баффы/дебаффы на цель, лечение, метки |
| `SELF` | Под ногами кастера (горизонтально), для мобильности — вертикально за спиной | Ауры, щиты на себя, рывки, телепорты |

Если у `TARGET`-заклинания нет цели в прицеле, оно применяется на себя (если `allow_self: true`) или показывает отказ «Нет цели».

### 5.3. Режимы каста

| Режим | Поведение ввода | Круг |
|---|---|---|
| `INSTANT` | Нажал — сработало (≤ 0.3 с) | Короткая вспышка круга |
| `CHARGED` | Удержание клавиши, отпускание после полной зарядки | Заполняется по мере каста; отпущено раньше `min_charge` — прерывание |
| `CHANNEL` | Удержание = длительное действие (луч, поток), мана списывается тиками | Полный круг, пульсирует, пока держишь |
| `TOGGLE` | Нажатие включает/выключает постоянный эффект (аура) | Маленький круг под ногами, пока активно |

Опция клиента: «Автокаст по готовности» — `CHARGED` выпускается сам при 100% (для удобства и доступности).

### 5.4. Редкость [✔ 8 уровней]

Редкость определяет **сложность получения, бюджет силы, сложность мастерства и масштаб круга**. Редкость конкретного заклинания не повышается.

| № | Редкость | ID | Цвет | Бюджет силы* | Множитель опыта мастерства | Слоёв круга | Базовый радиус круга |
|---:|---|---|---|---:|---:|---:|---:|
| 1 | Обычное | `common` | `#D9D9D9` | 1.00 | ×1.0 | 1 | 0.6 бл |
| 2 | Необычное | `uncommon` | `#55FF55` | 1.15 | ×1.2 | 2 | 0.7 |
| 3 | Редкое | `rare` | `#5599FF` | 1.30 | ×1.45 | 2 | 0.8 |
| 4 | Эпическое | `epic` | `#AA44FF` | 1.50 | ×1.75 | 3 | 0.95 |
| 5 | Легендарное | `legendary` | `#FFAA00` | 1.75 | ×2.1 | 3 + руны | 1.1 |
| 6 | Мифическое | `mythic` | `#FF5555` | 2.05 | ×2.5 | 4 | 1.25 |
| 7 | Древнее | `ancient` | `#B5884A` | 2.40 | ×3.0 | 4 + древние знаки | 1.4 |
| 8 | Божественное | `divine` | `#FFF2A8` | 2.80 | ×3.6 | 5 (лимит масштаба) | 1.6 |

\* **Бюджет силы** — это не множитель урона, а ориентир «сколько суммарной пользы на единицу маны» при балансе. Редкое заклинание не обязано бить сильнее — оно может делать больше вещей.

**Правило цвета:** основной цвет круга задаёт **школа**, редкость — только обводку, рамку иконки и маркер-символ (◇, ◆, ★, ✦…), чтобы различимость не зависела только от цвета.

## 6. Изучение свитков

### 6.1. Процесс [✔]

1. ПКМ свитком → экран подтверждения: имя, школа, редкость, краткое описание, требования.
2. Удержание ПКМ ~2 с (анимация чтения, круг школы на листе). Прерывание — свиток не тратится.
3. Сервер проверяет требования, добавляет `spellId` в знания игрока, свиток расходуется.
4. Тост «Изучено: ⟨название⟩» + кнопка «Открыть в гримуаре».

### 6.2. Требования к изучению [≈]

| Редкость | Требование |
|---|---|
| Обычное–Редкое | Нет |
| Эпическое | Любое заклинание этой школы на мастерстве ≥ 5 |
| Легендарное | Любое заклинание этой школы на мастерстве ≥ 10 **или** резонанс этой школы ≥ 4 |
| Мифическое и выше | Мастерство ≥ 10 у заклинания этой школы **и** резонанс ≥ 6 (хотя бы когда-то достигнутый) |
| Высшие школы (Свет, Тьма, Астрал) | Дополнительно — предмет-ключ «Печать постижения ⟨школы⟩» в инвентаре, расходуется при первом изучении заклинания школы (§11.4) |

Требования настраиваются в серверном конфиге (можно отключить полностью).

### 6.3. Дубликаты [✔ идея / ≈ числа]

Повторный свиток уже изученного заклинания нельзя прочитать — его можно:

- **Рассеять** (ПКМ с Shift) → +X опыта мастерства этому заклинанию (≈ 15% от следующего уровня; не выше уровня 9 — вехи 10 и 15 только через практику);
- **Разобрать на алтаре** → «Чернила эфира» (ресурс для крафта фокусов и ритуала смены школы).

Обмен свитками между игроками работает естественно — свиток это обычный предмет.

### 6.4. Забыть заклинание

Нельзя по умолчанию [✔ «навсегда»]. Для админов: команда `/orbis spell forget`. Опция сервера `allowForgetting` для модпаков.

## 7. Мастерство (15 уровней и вехи)

### 7.1. Принципы [✔]

- Опыт начисляется за **результат**, а не за нажатие.
- 15 уровней; уровни 2–4, 6–9, 11–14 — рост характеристик; **5, 10, 15 — вехи**, меняющие поведение.
- Чем выше редкость, тем больше опыта нужно (множитель §5.4).
- Мастерство растёт у любого заклинания независимо от доминантной школы.

### 7.2. Результативные действия

| Категория | Когда начисляется | Вес |
|---|---|---|
| Атака | Урон ≥ 1 HP по живой враждебной/нейтральной цели (первое попадание за каст + доля дополнительных) | 1.0 + 0.25 за каждую доп. цель (макс. +1.0) |
| Добивание | Цель умерла от заклинания | +0.5 |
| Контроль | Эффект наложен на неиммунную цель | 1.0 |
| Лечение / Щит | Реально восстановленные HP / реально поглощённый урон (не overheal) | 1.0 за 20% max HP цели, макс. 2.0 за каст |
| Поддержка | Бафф на союзника, который в течение действия вступил в бой | 1.0 |
| Мобильность | Перемещение ≥ 3 блоков **в бою** | 1.0; вне боя — 0.3 и лимит 30 за игровые сутки |

**Антифарм [≈]:** манекены, стойки брони, свои призывы — 0; мобы из спавнеров — ×0.5; одна и та же цель — затухание ×0.5 после 20 попаданий за 5 мин; PvP — ×0.25 с лимитом на одного игрока в час.

### 7.3. Кривая опыта [≈]

```
xpRequired(L → L+1) = round(10 × 1.25^(L−1) × rarityMult)
xpGain              = categoryWeight × cycleWeight × serverRate
cycleWeight         = clamp((castSec + cooldownSec) / 3, 1, 12)
```

`cycleWeight` уравнивает частые дешёвые и редкие тяжёлые заклинания. Ориентир для Обычного заклинания: веха 5 ≈ 30–45 минут активного использования, 10 ≈ 3–4 ч, 15 ≈ 8–10 ч.

### 7.4. Обычные уровни

- +3% к `primary_stat` за каждый обычный уровень (итого 12 уровней ≈ +36%).
- Линейно до −12% стоимости маны и до −10% времени каста к 15 уровню.

### 7.5. Вехи [✔]

| Уровень | Название | Что меняется | Пример (Огненный шар) |
|---|---|---|---|
| **5** | **Пробуждение** | Количественное изменение поведения | Выпускаются 2 шара |
| **10** | **Преображение** | Новая механика | Шары крупнее и поджигают землю на 3 с |
| **15** | **Апогей** | Финальная трансформация, меняет внешний вид круга и эффекта | При контакте шары взрываются (AoE), круг получает внешний огненный венец |

Правила:

- Каждая веха описана в карточке заклинания **до** её получения (игрок знает, к чему идёт).
- Вехи добавляют геометрию в круг (кольцо, руну, сателлит) — по кругу видно мастерство игрока.
- Опция игрока: **отключить отдельную веху** (например, если поведение мешает). Статы обычных уровней остаются.

## 8. Мана и жизненный цикл каста

### 8.1. Мана [≈]

| Параметр | Значение |
|---|---|
| Базовая макс. мана | 100 (атрибут `orbisarcana:max_mana`) |
| Регенерация | 2/с в бою, 5/с через 5 с вне боя (атрибут `mana_regen`) |
| Смерть | Мана = 50% макс. |
| Предметы | Зелье маны (+40, общий КД 30 с) |

### 8.2. Состояния каста

```
IDLE → REQUESTED → CASTING (круг заряжается) → RELEASED (эффект) → COOLDOWN → IDLE
                       └→ INTERRUPTED (круг рассыпается) → IDLE
```

- Сервер — единственный источник истины: проверяет знание, ману, КД, цель, дальность.
- Стоимость, сила и время **снимаются в момент старта** (переодевание фокуса во время каста ничего не даёт).
- Глобальная пауза между кастами (GCD): 0.25 с.

### 8.3. Прерывание и частичная потеря маны [✔ принцип / ≈ числа]

Мана **резервируется** при старте и окончательно списывается при выпуске. При прерывании теряется часть:

```
lost = cost × (0.10 + 0.40 × progress)    // progress 0..1
```

То есть отмена в самом начале стоит 10%, сорванный почти готовый каст — до 50%.

| Причина | Потеря |
|---|---|
| Сам отпустил раньше `min_charge` / отменил | По формуле |
| Урон ≥ 15% макс. HP (шанс сбития = 0.5 − `cast_stability`) | По формуле |
| Оглушение, «тишина», смерть, смена измерения | По формуле (при смерти — неважно) |
| Цель исчезла / вышла из дальности | 10% (не вина игрока) |

### 8.4. Движение во время каста

- `CHARGED` / `CHANNEL`: скорость ×0.65, спринт сбрасывается.
- Атака оружием прерывает `CHARGED`.
- Круг следует за игроком (для `DIRECTIONAL`/`SELF`); для `GROUND` точка фиксируется в момент старта, но игрок может «вести» её с замедлением (опция заклинания `ground_follow`).

## 9. Магические круги

Главная визуальная особенность мода.

### 9.1. Поведение [✔]

1. **Появление** (0.15 с): круг разворачивается из точки, слои раскрываются по очереди.
2. **Зарядка**: внешний обод заполняется по дуге синхронно с прогрессом каста, внутренние слои ускоряют вращение, руны загораются по одной.
3. **Выпуск**: вспышка, круг «схлопывается» в точку выпуска или рассыпается частицами.
4. **Прерывание**: круг трескается и гаснет (≤ 0.2 с), цвет тускнеет.

### 9.2. Размещение по типам

| Тип | Позиция | Ориентация |
|---|---|---|
| `DIRECTIONAL` | Пустые руки: 0.9 бл перед грудью. Посох: конец навершия. Фолиант: над страницами. Жезл: кончик | Перпендикулярно взгляду |
| `GROUND` | Точка попадания луча взгляда по блоку (макс. дальность заклинания), выравнивается по поверхности | По нормали поверхности |
| `TARGET` | Под ногами цели, радиус ≥ ширины хитбокса | Горизонтально |
| `SELF` | Под ногами игрока; для рывков — вертикально за спиной | Горизонтально / вертикально |

### 9.3. Правило обзора: «круг не мешает видеть» [✔]

Для **собственного** `DIRECTIONAL`-круга в виде от первого лица:

- Круг рисуется **смещённым** вниз-вправо (в сторону ведущей руки), центр экрана не перекрывается;
- Внутренняя область круга прозрачна; непрозрачность линий 35–60%, растёт к моменту выпуска;
- Экранная доля ограничена: круг не занимает более **25% высоты экрана** (если масштаб выше — он отодвигается дальше от камеры, а не растёт на экране);
- При прицеливании через подзорную трубу/лук — круг скрывается;
- Опции клиента: прозрачность, масштаб «своих» кругов, режим «только обод», полное отключение.

Наблюдатели и вид от третьего лица видят круг в полном размере.

### 9.4. Размер круга

```
radius = baseRadius(rarity) × (1 + 0.02 × (mastery − 1)) × behaviorScale × focusScale
```

- `GROUND`/`TARGET` масштабируются по радиусу эффекта заклинания (круг = граница зоны — это информативно для противника).
- Абсолютный предел — 6 блоков (Божественное, AoE); от первого лица действует лимит §9.3.

### 9.5. Слои круга

| Слой | Зависит от | Пример |
|---|---|---|
| Обод (прогресс) | Всегда | Кольцо, заполняется по дуге |
| Геометрия школы | Школа | Огонь — треугольники; Лёд — шестиугольники; Астрал — орбиты |
| Руны | Заклинание | Уникальный набор глифов |
| Слои редкости | Редкость | Доп. кольца, «эхо»-проекции, древние знаки |
| Вехи | Мастерство 5/10/15 | +сателлит, +внешний венец, +смена анимации |
| Печать доминанты | Если школа заклинания = доминанта | Тонкая декоративная надстройка цвета школы |

### 9.6. Описание круга данными

Круг описывается JSON-ресурсом (клиентский ресурспак), что позволяет аддонам и художникам делать круги без кода:

```json
{
  "layers": [
    { "type": "ring", "radius": 1.0, "width": 0.06, "progress": true },
    { "type": "polygon", "sides": 3, "radius": 0.8, "rotate_speed": 30, "count": 2 },
    { "type": "glyph_ring", "radius": 0.65, "glyphs": "orbisarcana:fire_runes", "count": 8, "light_up_with_progress": true },
    { "type": "texture", "texture": "orbisarcana:circle/fire_core", "radius": 0.4, "rotate_speed": -60 }
  ],
  "milestone_layers": {
    "5":  [{ "type": "satellite", "count": 2, "radius": 1.15 }],
    "15": [{ "type": "ring", "radius": 1.25, "width": 0.03, "style": "flame_crown" }]
  }
}
```

### 9.7. Реализация рендера [≈]

- Собственный `RenderType` (аддитивное смешивание, без записи в depth, двустороннее), квады генерируются процедурно, глифы — из атласа текстур.
- Анимация на клиенте по `startTick` и `duration` из пакета `CastStarted` — сервер не стримит координаты.
- LOD: дальше 32 блоков — только обод; дальше 64 — не рисуется. Лимит активных кругов на клиенте (по умолчанию 48), приоритет — ближайшие и свои.
- Совместимость с шейдерами (Iris): обязательный тест; при проблемах — режим «частицы вместо мешей».
- **Механика не зависит от круга**: отключённый VFX не меняет геймплей.

## 10. Школы, резонанс и привязка

### 10.1. Десять школ [✔]

| Школа | ID | Тип | Роль |
|---|---|---|---|
| Огонь | `fire` | стихийная | Урон, давление, горение |
| Земля | `earth` | стихийная | Защита, позиционирование |
| Вода | `water` | стихийная | Лечение, течение, отталкивание |
| Воздух | `air` | стихийная | Мобильность, траектории |
| Лёд | `ice` | стихийная | Замедление, заморозка |
| Молния | `lightning` | стихийная | Цепи, скорость, прерывание |
| Природа | `nature` | стихийная | Зоны, удержание, восстановление |
| Свет | `light` | высшая | Очищение, щиты, поддержка |
| Тьма | `dark` | высшая | Проклятия, метки, риск/выгода |
| Астрал | `astral` | высшая | Пространство, гравитация, созвездия |

Высшие школы не «сильнее» — они сложнее в доступе и механиках.

### 10.2. Доминантная школа [✔]

- В каждый момент активна **одна** доминанта (или нейтральное состояние без неё).
- Доминанта даёт: **Отзвук** (уникальная механика школы), корневой пассив, ветки талантов, печать доминанты на кругах, **+10% силы и −5% стоимости** заклинаний школы [≈].
- Все изученные заклинания других школ доступны всегда.

### 10.3. Резонанс [✔ структура]

- Уровни **0–10**, отдельно для каждой школы, растут **только пока школа — доминанта**.
- Опыт резонанса = опыт мастерства от заклинаний этой школы × 0.5 (+ небольшая доля от заклинаний других школ: ×0.1, чтобы не было «мёртвых» школ без заклинаний).
- Резонанс **не теряется** при смене школы — он «заморожен» и восстанавливается при возвращении.

| Резонанс | Награда |
|---|---|
| 1 | Корневой пассив, Отзвук |
| 3 | Очко таланта |
| 5 | Отзвук усиливается (2-я ступень) |
| 6 | Очко таланта |
| 9 | Очко таланта |
| 10 | Печать доминанты становится «полной» (визуал), +5% к силе школы |

### 10.4. Дерево талантов [✔]

Каждая школа: **1 корневой пассив (бесплатно) + 2 ветви по 2 узла**. Узлы одноранговые, второй узел ветви требует первого. **3 очка на 4 узла** — взять всё нельзя, приходится выбирать.

Сброс очков школы: у алтаря резонанса за «Чернила эфира» [≈].

### 10.5. Отзвуки и таланты школ [≈]

| Школа | Отзвук (механика) | Корень | Ветвь A (нападение) | Ветвь B (защита/контроль) |
|---|---|---|---|---|
| **Огонь** | **Жар** 0–5: стаки на цели от огня; на 5 — вспышка-взрыв (r2) | *Угли*: горение от твоих заклинаний длится +30% | *Раздувание* (взрыв Жара поджигает соседей) → *Огненный венец* (каждый 3-й огненный каст бесплатен) | *Закалка* (иммунитет к поджогу) → *Пепельный щит* (получая урон в огне — щит 4 HP, КД 20 с) |
| **Земля** | **Оплот**: поглощённый урон копит заряд; следующий атакующий каст выпускает волну | *Каменный стержень*: +20% устойчивости каста стоя на земле | *Разлом* (волна Оплота шире) → *Резонанс пластов* (волна оглушает на 0.5 с) | *Крепость* (−10% урона при Оплоте ≥ 50%) → *Несокрушимый узор* (смертельный удар оставляет 1 HP, КД 5 мин) |
| **Вода** | **Поток**: лечение/поддержка дают стак; 3 стака — следующий каст мгновенный | *Живая волна*: +10% лечения | *Прибой* (отталкивание +50%) → *Обратное течение* (сбитый с ног враг замедлен) | *Источник* (лечение перекидывается на 2-го союзника 30%) → *Милость прилива* (снятие 1 дебаффа при лечении, КД 10 с) |
| **Воздух** | **Импульс**: движение в бою копит заряд; рывки тратят его на усиление | *Лёгкий шаг*: нет урона от падения ≤ 10 бл | *Остриё вихря* (снаряды быстрее на 30%) → *Штормовой след* (рывки оставляют режущий поток) | *Парение* (медленное падение после рывка) → *Уклончивый узор* (10% шанс уклониться от снаряда) |
| **Лёд** | **Иней** 0–5: замедление стаками; на 5 — заморозка 1.5 с (боссы — сильное замедление) | *Холодная кровь*: −штраф движения при касте льда | *Кристаллизация* (урон по замороженным +25%) → *Ледяная роза* (разбивание заморозки — осколки вокруг) | *Тихая зима* (атакующий в ближнем бою замедлен) → *Белая стена* (при HP < 30% — ледяной панцирь, КД 90 с) |
| **Молния** | **Проводимость**: попадания помечают цель; следующий разряд перескакивает на помеченных | *Проводник*: метка держится 6 с вместо 4 | *Расщепление* (+1 перескок) → *Грозовая сеть* (между помеченными — слабые дуги) | *Громоотвод* (прерывание каста у мобов) → *Обратный ток* (получив удар, бьёшь атакующего искрой, КД 4 с) |
| **Природа** | **Прорастание**: результативные касты сажают ростки (макс. 3), созревают через 5 с — лечат/жалят | *Семя*: ростки созревают на 1 с быстрее | *Шипастые ветви* (ростки атакуют) → *Дикий рост* (созревший росток опутывает) | *Целительная роща* (ростки лечат больше) → *Великая крона* (+15% лечения рядом с листвой/деревом) |
| **Свет** | **Сияние**: защита и лечение копят заряд; полный — импульс очищения союзников вокруг | *Искра*: overheal 25% → щит (макс. 4 HP) | *Обличение* (+20% урона по нежити и отмеченным) → *Луч возмездия* (импульс Сияния наносит урон) | *Покров* (импульс даёт щит) → *Солнечный обет* (союзники в радиусе 6 получают −5% урона) |
| **Тьма** | **Сумрак**: дебаффы оставляют метки; удар по метке поглощает её — урон + мана | *Теневая метка*: +2 маны за поглощение | *Поглощение* (вампиризм 5% от магии Тьмы) → *Затмение* (поглощение 3 меток — вспышка ослепления) | *Покров ночи* (невидимость 2 с после убийства, КД 30 с) → *Слепое пятно* (мобы теряют цель при твоём телепорте) |
| **Астрал** | **Созвездие**: касты ставят звёзды (макс. 3); соединение 3 звёзд — гравитационный импульс в треугольнике | *Первая звезда*: звёзды живут 12 с вместо 8 | *Звёздная орбита* (импульс наносит урон ×1.5) → *Небесная геометрия* (возможна 4-я звезда, ромб = двойной импульс) | *Искривление* (−20% урона от снарядов при наличии звезды рядом) → *Нулевой момент* (импульс притягивает тебя к центру — побег) |

### 10.6. Привязка, отвязка и смена школы [✔ схема / ≈ числа]

**Первая привязка** — бесплатна, на **Алтаре резонанса** (§11.3), требует хотя бы одно изученное заклинание школы (для высших — ещё и Печать постижения).

**Отвязка (в нейтральное состояние)** — на алтаре, бесплатно; таланты и Отзвук перестают работать, резонанс замораживается.

**Смена доминанты** — ритуал на алтаре (стартовые значения утверждены [✔], тонкая подстройка — плейтестом):

1. **Расчёт.** Экран показывает новую школу, стоимость, длительность Дисгармонии и КД смены. Ничего не списывается.
2. **Ритуал.** 10 с, над алтарём — большая мировая печать, игрок стоит в кругу. Урон/выход из круга — отмена, возврат 50% стоимости.
3. **Привязка.** Старая школа замораживается (резонанс и выбранные таланты сохраняются), новая активируется.
4. **Дисгармония** — штраф на 20 минут реального игрового времени:
   - сила заклинаний **новой** школы −15%;
   - резонанс новой школы растёт ×0.5;
   - Отзвук новой школы работает с 50% эффективностью;
   - заклинания **бывшей** школы −10% к силе (душа «помнит» старую связь).
5. **Пауза между сменами** — 1 игровой день (24 000 тиков, отсчёт по серверному времени).

**Стоимость смены [≈]:** «Чернила эфира» × (4 для стихийных, 8 для высших) + 5 уровней опыта. Возврат к школе, у которой резонанс ≥ 5, — со скидкой 50% («старый путь легче»).

Отношения школ (родственные/антиподы) **не** вводятся в v1 — это упрощает баланс; могут появиться в 1.x как модификатор Дисгармонии [?].

## 11. Предметы и блоки

### 11.1. Фокусы (катализаторы)

Каст разрешён и без предметов [✔]. Фокус меняет точку круга и даёт модификаторы.

| Тип | Рука | Особенность | Где круг |
|---|---|---|---|
| **Без фокуса** | — | Базовые значения | Перед грудью |
| **Жезл** | Основная/вторая | +10% скорости каста, −10% дальности; можно держать с оружием во второй руке | Кончик жезла |
| **Посох** | Двуручный | +15% силы, +20% дальности, +1 устойчивость каста | Навершие |
| **Фолиант** | Вторая рука | −10% стоимости, +мастерство-опыт 10% для своей школы | Над страницами |

Линейка v1 [≈]: каждый тип в 3 тирах (дерево/железо → золото+аметист → незерит) + школьные варианты эпического тира (например, «Посох угасшего солнца», огонь). Модели — Blockbench, анимация навершия при касте — через GeckoLib.

### 11.2. Аксессуары (Curios)

Кольца и амулеты через **Curios API** [✔ без своих слотов]. 12 предметов v1: по кольцу на каждую стихийную школу (+10% силы), 3 амулета (мана, регенерация, устойчивость каста), 2 особых (например, «Кольцо отзвука» — Отзвук копится на 20% быстрее).

**Решение по зависимости [✔]:** Curios — **необязательная** зависимость. Без него аксессуары не генерируются в луте, не крафтятся и скрыты в JEI/EMI; остальной мод работает полностью. Вся интеграция — в изолированном `compat/curios`.

### 11.3. Блоки

| Блок | Назначение |
|---|---|
| **Алтарь резонанса** | Привязка/отвязка/смена школы, сброс талантов, разбор дубликатов. Мультиблок-лайт: алтарь + 4 пьедестала (необязательны, ускоряют ритуал) |
| **Стол переписчика** | Крафт пустых свитков, чернил, улучшение фокусов |
| **Кристалл эфира (руда/жеода)** | Базовый магический ресурс в пещерах |

### 11.4. Ресурсы и прочее

- **Осколок эфира** — из руды; база для всего.
- **Чернила эфира** — разбор дубликатов / крафт; валюта ритуалов.
- **Печать постижения (Свет/Тьма/Астрал)** — ключ к высшей школе. В v1.0 крафт из редких материалов (Свет: звезда Нижнего мира + золото; Тьма: эхо-осколки Древнего города; Астрал: плод хоруса + жемчуг Края) [≈]. В v1.1 заменяются испытаниями.
- **Зелья маны**, **пустой свиток** (декоративная основа, свитки заклинаний не крафтятся).

Опция: каст на ПКМ, когда в руке фокус.

### 13.2. HUD

- Полоса маны (компактная, у хотбара, позиция настраивается).
- Иконка выбранного заклинания + КД + полоса каста.
- Индикатор Отзвука доминанты (стаки).
- Причина отказа каста — текст + иконка («Мало маны», «Перезарядка», «Нет цели», «Вне досягаемости»).

### 13.3. Радиальное меню [✔]

8 секторов × **3 набора**. В секторе — иконка, рамка редкости, КД. В центре — название и стоимость. Пустые сектора не выбираются.

### 13.4. Гримуар (единое окно, вкладки)

| Вкладка | Содержимое |
|---|---|
| **Знания** | Сетка всех изученных заклинаний: фильтры по школе, редкости, типу; поиск; сортировка по мастерству |
| **Карточка заклинания** | Описание, тип каста и размещения, стоимость, КД, урон/эффект с учётом мастерства, фокуса и доминанты; полоса мастерства; **вехи 5/10/15** (что дают, полученные отмечены); **3D-превью круга** (вращаемое, ползунок «уровень мастерства» показывает, как круг изменится) |
| **Радиальное меню** | Перетаскивание заклинаний из списка в сектора, 3 набора, предпросмотр колеса |
| **Школы** | 10 школ: резонанс каждой, текущая доминанта, описание Отзвука; дерево талантов (корень + 2 ветви) с подсказками; кнопка «Привязаться» неактивна вне алтаря, показывает условия |
| **Летопись** (1.1) | Лор и записи из структур |

Неизученные заклинания в гримуаре **не показываются** (кроме счётчика «Изучено 12 / 30» и силуэтов по школам — опция).

### 13.5. Доступность

Масштаб UI, режим без мерцания, высококонтрастные круги, отключение тряски, автокаст, текстовые подписи к цветовым индикаторам.

## 15. Архитектура кода

### 15.1. Принципы

1. **Сервер — авторитет.** Клиент отправляет только намерение (`CastRequest`), всё считает сервер.
2. **Данные отдельно от кода.** Параметры заклинаний — датапак; поведение — Java-классы `SpellBehavior`.
3. **Чистое ядро.** Формулы, машина состояний каста, расчёт мастерства — в пакете `core` без зависимостей от Minecraft, покрыты JUnit-тестами.
4. **Клиентский код изолирован** (`client/`), сервер запускается без него.
5. **Совместимость через изоляцию** (`compat/<mod>`, загружается только при наличии мода).

### 15.2. Структура пакетов

```
com.orbisarcana
├─ api/            публичный API для аддонов (стабильный после 1.0)
├─ core/           чистая Java: формулы, CastStateMachine, MasteryMath, Resonance
├─ registry/       регистрация: блоки, предметы, атрибуты, damage types, реестры
├─ spell/          SpellDefinition (codec), SpellBehavior и реализации, CastService
├─ school/         School, Echo (Отзвуки), TalentTree, AttunementService
├─ progression/    KnownSpells, MasteryService, XP-события, антифарм
├─ mana/           ManaService, бой/регенерация
├─ data/           Data Attachments, миграции схемы
├─ network/        payloads C2S/S2C
├─ item/ block/    фокусы, свитки, алтарь
├─ world/          структуры, loot modifiers, торговля
├─ client/         ui/ (гримуар, радиал), circle/ (рендер кругов), fx/, anim/
├─ compat/         curios/, jei/, emi/, jade/, ftbchunks/ ...
└─ gametest/       сценарии GameTest
```

### 15.3. Данные игрока (NeoForge Data Attachments)

| Attachment | Содержимое | Сохраняется | При смерти | Синхр. |
|---|---|---|---|---|
| `knowledge` | изученные заклинания, мастерство `{spellId → level, xp}`, отключённые вехи | да | копируется | полный при входе, затем дельты |
| `attunement` | доминанта, резонанс по школам, таланты по школам, Дисгармония до, КД смены | да | копируется | дельты |
| `loadout` | 3 × 8 слотов | да | копируется | по изменению |
| `resources` | мана, КД `{spellId → gameTime окончания}` | да | мана 50%, КД сохраняются | мана ≤ 4 раз/с |
| `session` | активный каст, стаки Отзвука | нет | сброс | события |

Схема версионируется (`schema: 1`), есть миграции. Неизвестный `spellId` (удалённый аддон) уходит в `archived` и восстанавливается, если аддон вернули.

### 15.4. Заклинание как данные

`data/<namespace>/orbisarcana/spell/fireball.json`:

```json
{
  "school": "orbisarcana:fire",
  "rarity": "orbisarcana:common",
  "behavior": "orbisarcana:projectile",
  "targeting": "directional",
  "cast": { "mode": "charged", "ticks": 14, "min_ticks": 8 },
  "cost": 10,
  "cooldown_ticks": 40,
  "primary_stat": "damage",
  "params": { "damage": 6.0, "speed": 1.8, "range": 32, "ignite_ticks": 60, "count": 1, "size": 0.5 },
  "milestones": {
    "5":  { "params": { "count": 2, "spread_deg": 8 } },
    "10": { "params": { "size": 0.8, "ground_fire_ticks": 60 } },
    "15": { "params": { "explode_radius": 2.5 } }
  },
  "circle": "orbisarcana:fireball",
  "icon": "orbisarcana:textures/spell/fireball.png",
  "xp_category": "attack",
  "enabled": true
}
```

- Вехи могут менять только параметры, которые объявил `SpellBehavior` (валидация codec'ом с понятной ошибкой).
- Если вехе нужна логика, которой нет в параметрах — поведение реализует хук `onMilestone(level)`.
- Реестр датапаковый (синхронизируется клиенту); изменения применяются при перезапуске мира.

### 15.5. Поведения v1 (`SpellBehavior`)

`projectile`, `beam`, `cone`, `chain`, `zone`, `wall`, `trap`, `dash`, `blink`, `shield`, `aura`, `heal`, `status`, `summon`, `orbit`. 30 заклинаний собираются из этих 15 типов + индивидуальных хуков.

### 15.6. Сеть

```
C2S  CastRequest(spellId, actionId, aim{dir, point?, targetId?})
C2S  CastRelease(castId) | CastCancel(castId)
C2S  LoadoutUpdate(page, slot, spellId?)
C2S  LearnScroll(hand) | TalentPick(school, node) | AltarAction(...)
S2C  CastStarted(castId, spellId, casterId, startTick, duration, anchor, circleState)
S2C  CastResolved / CastInterrupted / CastDenied(reason)
S2C  ManaSync, CooldownSet, KnowledgeDelta, AttunementDelta, FullSync
```

Защита: лимит C2S-пакетов, валидация точки прицела (в пределах луча от глаз), идемпотентность `actionId`. Чужие касты рассылаются только игрокам, отслеживающим кастера.

### 15.7. Урон

- Свой `damage_type` на каждую школу (`orbisarcana:fire_magic` …), теги `orbisarcana:magic`, `is_fire` не используется (иначе огнеупорные мобы неуязвимы — делаем ×0.5).
- Броня работает; зачарование «Защита» снижает магию.
- Молния — без ванильного `LightningBolt` (не превращаем свиней и жителей).
- Атрибуты для силы магии регистрируются как обычные `Attribute` — совместимы с модами, читающими атрибуты.

### 15.8. Конфиги и команды

- **Server config:** множители опыта, маны, урона по школам; включение требований изучения; `allowForgetting`; разрушение блоков; PvP-множитель опыта; КД смены школы; список отключённых заклинаний.
- **Client config:** круги (прозрачность, масштаб своих, LOD, лимит), HUD, автокаст, доступность.
- **Команды** `/orbis` (уровень прав 2): `spell learn|forget|mastery`, `school set|resonance|reset`, `mana`, `debug circles`.

## 16. API для аддонов

Цель [✔]: аддон без форка может добавить школу, заклинание, круг, Отзвук, предмет-фокус.

| Точка расширения | Как |
|---|---|
| Новое заклинание из существующих поведений | Только JSON в датапаке + текстуры/круг в ресурспаке |
| Новое поведение | Регистрация `SpellBehavior` в реестре `orbisarcana:spell_behavior` |
| Новая школа | Реестр `orbisarcana:school` (цвет, геометрия, Отзвук, дерево талантов) |
| Новая редкость | Не поддерживается (8 фиксированы) [✔] |
| Новый круг / слой круга | JSON круга; новый тип слоя — клиентский реестр `circle_layer_type` |
| Отзвук школы | Интерфейс `SchoolEcho` |
| Таланты | Data-driven узлы с модификаторами атрибутов + интерфейс `TalentEffect` для логики |
| События (NeoForge EventBus) | `SpellCastEvent.Pre/Post` (отменяемый), `SpellLearnEvent`, `MasteryLevelUpEvent`, `MilestoneReachedEvent`, `AttunementChangeEvent`, `ManaChangeEvent`, `SpellDamageEvent` |
| Сервисы | `OrbisArcanaAPI.get()` → `knowledge(player)`, `mana(player)`, `attunement(player)`, `cast(player, spellId)` |
| Фокус | Data component `orbisarcana:focus` на любом предмете — другой мод может сделать свой меч фокусом |

API публикуется отдельным артефактом (`orbisarcana-api`) в Maven (GitHub Packages / Modrinth Maven). Аннотации `@ApiStatus.Experimental` до 1.0. В репозитории — **пример аддона** (`example-addon/`).

## 19. Производительность и тестирование

### 19.1. Бюджеты [≈]

- Сервер: ≤ 0.5 мс/тик на 20 активных магов.
- Клиент: ≤ 1 мс/кадр на 30 кругов на экране; круги — батч одного `RenderType`.

### 20.3. Политика расширения каталога

- Каждое обновление добавляет пакет заклинаний (ориентир 5–10), не ломая сохранения: новые ID, старые не переименовываются (иначе — запись в `legacy_ids`).
- Чек-лист нового заклинания: JSON + поведение (или существующее) → круг JSON → иконка → локализация RU/EN → источник в луте → GameTest каста и трёх вех → строка в changelog.
- Высшие редкости (Легендарное → Божественное) вводятся по нарастающей вместе с контентом, который их выдаёт.
