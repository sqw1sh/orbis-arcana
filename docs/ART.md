# Orbis Arcana — арт-библия и конвейер ассетов

Основа для этапов V1–V8 (`ROADMAP.md`). Референсы: UI-кит «Sigilweave» и концепты пользователя (`Downloads/референсы`).

## 1. Стиль

**«Тёмная алхимия × современная читаемость».** Тёмные сланцевые панели, тонкие золотые рамки с угловыми
орнаментами, бирюзовый акцент для действий интерфейса, цвет школы — для подсветки всего, что к ней относится.
Пиксельная сетка Minecraft сохраняется (рамки и иконки кратны пикселю GUI), но иерархия и отступы — как в
современном интерфейсе: крупный заголовок, вторичный текст приглушён, одно главное действие на экран.

## 3. Рунный язык

Общий алфавит для кругов, иконок, интерфейса и структур — 32 глифа (16×16, линия 1–2 px), по смыслу:
**сила, контроль, связь, защита, перенос, ускорение, замедление, разрушение, созидание, исцеление, призыв,
изгнание, взгляд, сокрытие, притяжение, отталкивание, начало, конец, цикл, порог, ключ, печать, путь, зеркало,
искра, поток, корень, буря, покой, тень, свет, звезда.** Круг заклинания собирается из рун его эффекта, поэтому
одинаковые по смыслу заклинания разных школ узнаваемы. Глифы рисуются в V1 (интерфейс) и используются в V3 (круги).

## 4. Разрешения

- **Блоки:** 16×16, ванильная палитра и освещённость (сочетаются с глубинным сланцем, камнем и т.п.).
- **3D-предметы (GeckoLib):** текстура 32×32–64×64 на модель; плотность ≈ 2 px на 1/16 блока для мелких деталей.
- **Круги и VFX:** 128–256 px, эмиссивные слои отдельно от базовых.
- **Иконки заклинаний:** 32×32 с рамкой редкости (рамка рисуется кодом, не в иконке).
- **Бюджет геометрии:** ручные предметы ≤ 300 кубов/граней, сущности ≤ 1500; детали (заклёпки, гравировка) — в текстуре.

## 5. Конвейер

| Что | Исходник | Экспорт | Куда |
|---|---|---|---|
| 3D-модели (предметы, сущности, блоки) | `art/models/<id>.bbmodel` (формат GeckoLib, mod id `orbisarcana`, object id = имя файла) | Blockbench + плагин GeckoLib (или MCP: `geckolib_export_model`, `geckolib_export_animations`), затем `node tools/art.cjs` | `assets/orbisarcana/geckolib/models/<тип>/<id>.geo.json`, `geckolib/animations/<тип>/<id>.animation.json`, `textures/<тип>/<id>.png`; для предметов ещё `items/<id>.json` и `models/item/<id>.json` |
| Анимации мага | `art/animations/caster.bbmodel` (риг игрока: head, torso, right_arm, left_arm, right_leg, left_leg) | `geckolib_export_animations` | `assets/orbisarcana/player_animations/caster.json`; ключ анимации — `orbisarcana:animation.<имя>` |
| Звуки | `art/sounds/<имя>.json` (рецепт слоёв) | `node tools/sfx.cjs` (нужен ffmpeg в PATH или `FFMPEG`) | `assets/orbisarcana/sounds/<имя>[_N].ogg` (WAV-промежуточные — `art/sounds/out/`, не в git) |
| UI-кит (панели, кнопки, вкладки, полосы, шар маны, радиальное меню, иконки, сигилы школ, рамка подсказок) | `tools/gui.cjs` | `node tools/gui.cjs` | `textures/gui/sprites/ui/*` (+ `.mcmeta` nine-slice), `textures/gui/sprites/tooltip/arcane_*`; в коде — `client/ui/Ui`, `OrbisButton` |
| Магические круги | `tools/circles.cjs` (SDF «неон»: пластины 10 школ, орнамент, печать, руны 32 глифа, трубка, филигрань, риски, вспышки) | `node tools/circles.cjs` | `textures/effect/circle_atlas.png` 2048² (раскладка — `client/circle/CircleAtlas`) |
| Объёмные украшения кругов (кристаллы-спутники) | `art/circle/*.bbmodel` | MCP `risky_eval`: `Cube#getGlobalVertexPositions` → JSON углов кубов | `assets/orbisarcana/orbisarcana/circle_model/*.json` (`CircleModels`) |
| Эффекты (VFX) | `art/vfx/particles/*.json` — Blockbench (Snowstorm), MCP `create_particle_effect` с `pack_root` = `art/vfx`, текстура `textures/vfx/sheet` | `node tools/art.cjs` копирует | `assets/orbisarcana/orbisarcana/vfx/*.json`; id = имя файла |
| Лист спрайтов VFX | `tools/vfx.cjs` (ячейки 64 px: точка, свечение, искра, звезда, кольцо, дым, угли; раскадровки пламени и дыма по 8 кадров; осколки, лист, капля, руна; молнии) | `node tools/vfx.cjs` | `textures/vfx/sheet.png` (+ копия в `art/vfx` для превью Blockbench) |
| 2D-текстуры (иконки, блоки) | `tools/textures.cjs` | `node tools/textures.cjs` | `textures/item`, `textures/block` |

Правила:
- `node tools/art.cjs --check` падает, если экспорт отсутствует или старше `.bbmodel` — запускать перед коммитом.
- Код: предмет реализует `GeoItem` и отдаёт рендер через `client/model/GeoModels.item(this)`;
  поза мага — `client/anim/CasterAnimations.play(player, id)`.
- Проверка в игре: `./gradlew :runClientShot -Pshots=geckolib,pose`.
